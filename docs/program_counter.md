# Program Counter

**R15** is the **Program Counter** (PC). It is readable and writeable:

- read: return the current instruction address plus 4 (due to the pipeline nature of the design).
- write: cause a branch operation

**The Least Significant Bit** (LSB) of the PC is zero: the instructions must be aligned to half-word or word address.

> [!note]
>
> When using some of the branch / memory read instructions to update the PC, you need to **set the LSB of the new PC value to 1** to indicate the Thumb state.
>
> Otherwise, **a fault exception can be triggered**, as it indicates an attempt to switch to use ARM instructions, which is not supported.
>
> In high-level programming languages (including C, C++), **the setting of LSB in branch target is handled by the compiler automatically**.

**It is less common to use data processing instructions to update the PC**.

- In most cases, branches and calls are handled by instructions dedicated to such operations.

**It is frequent to find memory read operations with PC as base address register with address offsets generated by immediate values in the instructions**.

- The value of PC is useful for accessing literal data stored in program memory.
