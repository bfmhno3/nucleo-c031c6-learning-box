# Register Names in Programming

| Register | Possible Register Names |
| :---- | :---- |
| R0-R12 | `R0`, `R1`, ..., `R12`, `r0`, `r1`, ..., `r12` |
| R13 | `R13`, `r13`, `SP`, `sp` |
| R14 | `R14`, `r14`, `LR`, `lr` |
| R15 | `R15`, `r15`, `PC`, `pc` |
| RSR | `PSR`, `APSR`, `EPSR`, `IPSR` |

- Register name MSP and PSP are used in special register access instructions (`MRS`, `MSR`).
